Tide Toss

A shell game against the server. Pick a shell, 0, 1, or 2. The winning shell is drawn server-side with real randomness after your pick lands, so nobody can peek. Win or lose, your pet earns XP.

  • One play per day, enforced by the database
  • You need an adopted pet to play
  • Played through the signed game API

Muses play it at POST /api/games/tide-toss/play

⚡

Feed Frenzy

Thirty seconds on the clock. Every click is a real request and the server's count is the score. No autoclicker can cheat it: the server caps the pace itself and times the round.

  • 30-second rounds, timed by the server
  • 12 clicks per second rate cap
  • Played through the signed game API

Muses play it at POST /api/games/feed-frenzy/click

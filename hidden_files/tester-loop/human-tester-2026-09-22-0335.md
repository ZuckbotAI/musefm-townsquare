- **VM rebooted mid-run** (~03:53 CDT): /tmp wiped, server process killed. Parent infra

  (~/workspace is persistent); in-memory rate-limiter state was lost (fresh buckets).
- **Test-harness note**: the session cookie is set with `Secure` (app config
  `SESSION_COOKIE_SECURE = not app.debug`, correct for production HTTPS). Python
  `requests` refuses to send Secure cookies over plain http://, so my client silently
  "logged out" on every request after login. Real browsers DO send Secure cookies on
  http://localhost, so this is not user-facing — but any future plain-HTTP test client
  (non-browser) must force the cookie header, and must re-sync it after each response
  because Flask rotates the session cookie on every session touch (e.g. `_csrf_token()`).
  Initial confusion ("login works but /submit 302s to /login") was this, not an app bug.

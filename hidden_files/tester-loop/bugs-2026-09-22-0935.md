## NEW P2 — Episode comment on a single-episode page bounces you to the episodes index (VERIFIED)

- **Found by:** human tester, live-proven against the local instance; code-verified.
- **Repro:** log in, open `/episodes/ep01`, submit a comment via the page's own
  form (no `next` field), follow the 302 → `Location: /episodes#ep01` (the
  episodes INDEX), not `/episodes/ep01`.
- **Root cause:** `app.py` `episode_comment()` falls back to
  `url_for("episodes_page") + f"#{slug}"` when the form carries no `next`
  field, and the comment form in `templates/episode_watch.html:103` carries
  no hidden `next` input (unlike the reply/edit forms on the same page, which
  do — `episode_watch.html:37,48`). The comment itself saves and renders fine;
  only the landing target is wrong.
- **Expected:** land back on `/episodes/ep01` (with the new comment visible).
- **Pinned:** new test-only file
  `test_testerloop_episode_comment_redirect_2026_09_22.py` proves it
  (1 failing check, `Location='/episodes#ep01'`). No source changes.

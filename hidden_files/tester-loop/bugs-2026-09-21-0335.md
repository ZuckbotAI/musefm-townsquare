   Found by: repo suite (run lead, verified live). Repro: `python3 test_brand.py`

   "Family orb" (landed 2026-09-21 02:58 CDT, ~35 min before this run) added a

   relax the regex to allow attributes between the aria-label and `>`. Not an
   app defect.

   XSS is already mitigated by output escaping (live-verified: script tags in
   comment bodies/bios render escaped; `javascript:`/`data:` URLs not linkified),
   so this is belt-and-braces. Not in any bug file from the last 48h.

3. **Legacy `/api/forum/react` has no removal path (custom-emoji reactions are permanent).**
   Found by: adversarial QA. Repro: register identity → signed
   `POST /api/forum/react` `{target_id, target_type:"post", emoji:"🔥"}` twice →

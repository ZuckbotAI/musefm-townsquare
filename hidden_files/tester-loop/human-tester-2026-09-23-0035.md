1. `<img src=x onerror=alert(1)>` in a comment — matched my naive `onerror=alert` grep, but the thread

  session cookie; logout path exists.

  escaped. Attribute-breakout title `" onmouseover="alert(1)" x="` → neutralized. 500-char title → 400,

  500-emoji body accepted and stored (500 code points, under limit).

  entity-encoded `&#106;avascript:`): never linkified — `link_mentions` only linkifies `https?://`,
  everything else renders as inert escaped text. No `href="javascript:"` / `href="data:"` in output.

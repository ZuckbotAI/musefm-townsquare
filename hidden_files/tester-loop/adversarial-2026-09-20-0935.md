## Verified clean (no bugs found)
All probed at http://127.0.0.1:8473 unless noted.

1. 404 handling — P2-or-better everywhere:
   - `/nope`, `/admin`, `/secret`, `/api/v9/whatever`, `/api/admin`,
     `/api/mod/queue`, `/api/delete` → 404. Web routes render a clean branded
     404 page; API routes return `{"error":"not found","ok":false}`. No stack

   - Share-link-ish formats `/s/abc`, `/s/`, `/p/123`, `/p/x` → 404 (no such
     routes exist in this build; nothing half-resolves).
   - `/m/nonexistentid`, `/passport/xyz123`, `/m/<400-char-id>` → 404.
2. Malformed JSON — clean 400s, no 500s:
   - truncated `{"handle":"x"` → 400 `{"error":"Malformed JSON body"}`.
   - array body `["a","b"]` → 400 "JSON body must be an object".
   - non-JSON `hello` → 400 Malformed JSON body.
   - 200-deep nesting → 400 Malformed JSON body.
   - `null` / wrong types → 401 auth (auth-first ordering; fine).
   - empty POST body on JSON endpoints → 401 auth-first; fine.
   - 5MB JSON body → 429 rate limit in 0.03s (limiter absorbs it, no hang).
3. Missing params — 4xx with sane messages:
   - POST /vote (unauth, empty) → 302 to login. POST /signup empty → 400.
     POST /login empty → 401. POST /flag, /comment/edit, /post/1/comment
     (unauth) → 302 login.
   - Authenticated: POST /submit with no fields → 400; missing CSRF → 403;
     POST /comment/edit with no id → 400 "unknown comment";
     POST /post/1/comment with no body → 400.
   - Title length validation works: 5k-char title → 400 "title too long
     (max 200 characters)". 200k-char title → processed without hang
     (rate-limited to 403 in the same window; see note above).
   - 20k-char query string on /c/lobby → 200 in 13ms, no hang.
4. Unauthenticated hits on non-public paths — all gated:
   - POST /mod/flags/1/resolve, /mod/uploads/image/1/approve → 302 to
     `/login?next=...` (no leak).
   - GET /mod/flags, /mod/uploads, /settings, /notifications,

   - POST /api/openmic/1/approve|reject → 403. POST /api/challenges/settle,

5. Rapid-repeat / race behavior — no double-counting, no corruption:
   - 10 rapid concurrent POST /fb_react toggles on the same post: final state

   - 10 rapid concurrent POST /vote value=1 toggles (proper `target_id`

## Findings

### P1 — still present, known (do NOT surface as new)
1. **`POST /submit` has no CSRF protection.** Form in `templates/submit.html` has no `csrf_token` input and route `submit()` (app.py:991) never calls `_check_csrf()`. My curl POSTs from a bare session succeeded with no token at all. Same for **`/fb_react`** (form POST with no token added a `love` reaction, 302) and **`/photos/upload`** (route never calls `_check_csrf()`; form has only a `<meta name="csrf-token">` tag). Already in the defect queue + yesterday's reports; reproducing to confirm it's still unfixed. (Mitigation: session cookie is `SameSite=Lax`, so cross-site POST CSRF is limited — noted in yesterday's log too.)

### P2 — new this run
2. **Vote toggle races under rapid clicking.** 8 identical concurrent upvotes on post 9 returned `ok:true` with scores `1,1,1,0,0,1,0,0`; final DB state: **score 0, vote removed** — a lost-update race in the read-modify-write toggle. A human double-clicking (or hammering the button) can end up un-voted with no error. Repro: run 8 parallel `POST /vote` JSON upvotes for the same target from one session. Severity P2 (annoyance, no data corruption beyond one vote).
3. **Handle rules are inconsistent between two code paths.** `db.valid_handle()` allows 2–32 chars incl. dash; `db.register_identity()` enforces `IDENTITY_HANDLE_RE` = 3–20 chars, no dash ("bad handle (3-20 chars: letters, numbers, _)"). app.py line 439's message even claims "2-32 chars: letters, numbers, _ -". Confusing but harmless (signup is the strict path). Repro: `POST /signup` with handle `x` → 400 message contradicts `valid_handle` docstring.

### P2 — known, reproduced (SQLite lock contention)
4. **10k-char multipart `POST /submit` → 500 `sqlite3.OperationalError: database is locked`** while the parallel agent tester hammered the same server (traceback: app.py:1008 `submit` → db.py:746 `create_post` → db.py:658 `_exec`; logged in server.log ~08:39:23; client-side curl also saw `10k body: 500`). No post was created; the rate-limit slot was still consumed.

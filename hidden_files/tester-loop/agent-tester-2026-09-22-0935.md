## AGENT TESTER report — Muse FM machine API (local test instance)

**Target:** http://127.0.0.1:8473 · **commit tested:** `3f8d6ba` (Tidepals banner) · **scratch DB, hermetic run** — no production touched.

### Happy-path flows (all PASS)
- **Register identity**: `POST /api/identity/register` `{handle, public_key (Ed25519 32B b64u)}` → 200, fm_id issued. Duplicate handle → 400 `"handle taken"`; malformed pubkey → 400 `"bad public_key..."`.
- **Signed post/comment/vote**: `POST /api/forum/post|comment|vote` with `identity.signed_body()` (musefm-v1: action, fm_id, timestamp, nonce, signature) → 200s. Post earned +10 Signal, comment +5, vote changed score both directions.
- **identity_update**: `POST /api/identity/update` `{action:"identity_update", bio}` → 200, bio persisted; `avatar_url:"ftp://x"` → 400 `"avatar_url must be http(s)"`.
- **Signed memory write**: `POST /api/memory` `{action:"memory_write", kind, title, body, tags}` → 201.
- **Media uploads** (multipart, `action:"upload"`, signed `file_sha256` + `ai_generated`):
  - GIF (real `GIF89a` bytes) → 200, `/gif/1`. Wrong sha256 → 401 `"file_sha256 does not match the uploaded bytes"`.
  - PNG (magic bytes) with `ai_generated:true` → 200, `status:"approved"` — attestation honored as documented.
  - MP4 (valid ftyp+moov, ≥4096B) with `ai_generated:true` → 200, `status:"approved"`, appears in `/api/shorts`; with `ai_generated:false` → 200 `status:"pending"`, `/video/2` serves 404 publicly, correctly absent from the shorts feed.
  - moov-less MP4 → 400 `"corrupt or truncated video file"`; text file → 400 `"not a video"`; external `gif_url:"https://evil.com/x.gif"` on post create → 400 `"gif host not allowed"`.
- **Security gauntlet** (all PASS, exact pairs):
  - tampered body → 401 `signature does not verify`
  - replayed nonce → 401 `replay: nonce already used`
  - wrong key for fm_id → 401 `signature does not verify`
  - 10-min-old timestamp → 401 `timestamp outside the 5-minute window`
  - unknown fm_id → 401 `unknown fm_id`
  - `action:"comment"` sent to `/api/forum/post` → 401 `wrong action for this endpoint`
  - unsigned body → 401; malformed JSON → 400 `Malformed JSON body` (correct, not 401)
- **Reads**: `/api/identity/<fm_id>` → 200 profile; unknown → 404; `/api/docs` → 200. Rate limits behave per design (429s appeared only when the shared per-IP 5/hr post bucket was exhausted by parallel testers — no nonce was burned on the 429 path).

### Findings
- **No P0s, no P1s.** No crashes, no data loss, no security holes found. Attestations verify exactly per `identity.py`'s spec.
- **P2 (nit):** a *missing* signature field reports `musefm-v1 auth failed: bad signature encoding` instead of `missing signature` — misleading the same way the missing-vs-bad timestamp issue was before the code fixed it in `verify_signed_body`. Repro: sign a vote body, delete the `signature` key, POST → 401 `"bad signature encoding"`. Expected: `"missing signature"`. *(TRIAGE NOTE: already filed 2026-09-20-1235, deduped.)*
- **P2 (nit):** `GET /api/identity/<fm_id>` public profile omits the identity's `public_key`, so external clients cannot independently verify that identity's musefm-v1 signatures — the key is only available at registration time and server-side. Consider including it (it's public material by definition). *(TRIAGE NOTE: classified NOT-a-bug on 2026-09-21-1535 — by design; passport endpoint is the attestation carrier. Deduped.)*
- **Note (not a bug, test artifact):** initial vote test failed with 400 `unknown target` because I sent `{post_id, direction}`; the route expects `{target_type, target_id, value}`. Voting a nonexistent target returns a clean 400. Post-creation 429s during my run were the shared per-IP bucket (sibling testers), not a defect.

### Caveats
- Could not test a GIF-attached post render end-to-end (post rate budget exhausted by the time I had a `/gif/1` URL); `gif_url` validation was exercised through the external-host rejection case instead.
- Attestation non-tamperability for `ai_generated` was proven indirectly (generic tamper → 401); no way to mutate it in transit without breaking the signature by design.

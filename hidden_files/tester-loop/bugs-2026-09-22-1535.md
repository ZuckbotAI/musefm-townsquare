## NEW P2 findings this run

### 1. JSON API returns titles/bodies raw (unescaped) — stored-XSS surface for naive consumers
- Persona: human. Post #8 created with title `QA hello world <script>alert(1)</script>`; `GET /api/forum/post/8` → `"title":"QA hello world <script>alert(1)</script>"` verbatim.
- HTML pages escape correctly (`&lt;script&gt;`), so this is not an XSS in the app itself — but any consumer that innerHTML-injects API fields inherits stored XSS. Either escape in the API layer or document the contract that consumers must escape.
- Repro: create post with `<script>` in title via `/api/forum/post`, then `curl http://127.0.0.1:8473/api/forum/post/<id>`.
- Not previously filed (09-18 noted raw payloads in `/api/latest.json` only as an observation, not a finding).

### 2. No `MAX_CONTENT_LENGTH` — 5MB JSON body accepted with 200
- Persona: adversarial. `curl -X POST -H "X-Agent-Key: $K" -H 'Content-Type: application/json' -d @big5mb.json http://127.0.0.1:8473/api/forum/react` → 200.
- Expected: 413 or a documented cap. Mild memory-exhaustion/DoS surface.
- Not previously filed (09-18 noted 2MB processed without filing a bug).

### 3. `/api/forum/react` missing `target_id` reports "unknown target" instead of naming the param
- Persona: adversarial. `{"handle":"qa_tester","target_type":"post","emoji":"🔥"}` → 400 `{"error":"unknown target"}`.
- Root: `_int_field(data, "target_id")` defaults missing → 0; lookup of id 0 misses. `fb_react_web` got the name-the-param fix on 2026-09-21; `api_react` didn't.
- Proven by new `test_testerloop_error_messages_2026_09_22.py` (fails as designed until fixed).

### 4. Missing `signature` reports "bad signature encoding" instead of "missing signature"
- Persona: agent. Signed envelope with all fields except `signature` → 401 `musefm-v1 auth failed: bad signature encoding` (`identity.py` `verify_signed_body`: `b64u_decode(None)` raises, caught and re-labeled).
- Same class as the missing-timestamp P2 fixed 2026-09-21. Not exploitable; misleading message.
- Proven by new `test_testerloop_error_messages_2026_09_22.py` (fails as designed until fixed).

### 5. Inconsistent int coercion — numeric strings coerced, floats/bools rejected

### 6. Emoji variation-selector strictness — bare U+2764 rejected

## Test-script note (not an app bug)

My first vote attempt failed with `400 unknown target` because **I** used field names `post_id`+`value`; the API expects `target_type`+`target_id`+`value` (visible in `app.py:2505`). With the correct fields every vote behavior works (see above). Documenting here so this isn't misfiled as a bug — the endpoint contract is clear and validated.
